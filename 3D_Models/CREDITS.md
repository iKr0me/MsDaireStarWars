## X-wing variants in this kit

Both variants are adaptations of **Stylized X- Wing** by **Alexander Günther**, using the source and CC-BY-4.0 license above.

- `stylized_x-_wing_open_cockpit.glb`: cockpit canopy opened; R2 retained; named integration nodes added for the canopy, R2, and note launch; simple empty cockpit lining, seat, and dashboard added.
- `stylized_x-_wing_without_r2d2.glb`: exposed R2 dome removed; original astromech socket and closed canopy retained.

The untouched `stylized_x-_wing.glb` is also included. These modifications do not change the original model creator credit. The included manifest records original-file checksums for comparison.
